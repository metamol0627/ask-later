## 人へ：使い方は 1 つだけ

**完了したら `INBOX.md` を開いて、1 行書いてください。**それだけです。

```
P-001 done
```

- このファイルは**編集しなくてよい**。エージェントが更新する
- `P-001` は下の項目に付いている番号
- 「done」以外に、断る・条件を付ける・質問する、も自由文で書いてよい
  （例：`P-001 却下。理由は …` / `P-002 これは分かる範囲で答える。……`）
- プロジェクトのルートに `!pending_2.txt` のようなファイルがあれば未処理がある。0 件になると自動で消える

## エージェントへ

**状態行の書式は機械が読む。**崩さないこと。

```
- [ ] 状態: 未処理
- [x] 状態: 完了 (YYYY-MM-DD)
- [x] 状態: 取り下げ（理由）
- 期限: YYYY-MM-DD HH:MM        ← 過ぎると自動で「取り下げ」になる（任意）
```

自動で取り下げられた項目は状態行だけ書き換わり「# 未処理」の下に残る（機械は行を動かさない）。区切りで「# 解消済み」へ移すこと。

起票するときは「この項目が解けるまで棚上げする作業」と「この項目と関係なく続行する作業」を**必ず両方**書く。
棚上げするのは依存する作業だけで、残りは続ける。項目の書き方の例:

```
## [P-001] 依頼のタイトル

- [ ] 状態: 未処理
- 起票: YYYY-MM-DD
- 今何をしているか: （1〜3 行。人が文脈を思い出せるように）
- 依頼内容: （人がやること。コマンドや URL はそのまま貼る）
- 完了報告の書き方: `P-001 done`

**この項目が解けるまで棚上げする作業**
- …

**この項目と関係なく続行する作業**
- …
```
