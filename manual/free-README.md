# 無人運転の設計書（無料版）— 第 1 章と最小テンプレ

`ask-later`（MIT・無料の道具）に同梱している、有償の設計書「無人運転の設計書 — AI コーディングエージェントを止めずに回す規律（Claude Code での実装例つき）」の無料部分です。

## 入っているもの

| ファイル | 内容 |
|---|---|
| `01-why-it-stops.md` / `.html` | 第 1 章「なぜ止まるか——承認待ちの構造」。判断の留保と作業の停止は別のもの。承認待ちの 3 つの型。依存範囲を都度の判断に委ねない。棚上げが作る新しい失敗 |
| `templates/PENDING.md` | 依頼の台帳の雛形（`npx ask-later init` が置くものと同じ） |
| `templates/INBOX.md` | 人からの 1 行の雛形（同上） |
| `templates/CLAUDE.snippet.md` | CLAUDE.md に貼る規律の断片（`npx ask-later snippet` と同じ） |
| `templates/settings.hooks.json` | `.claude/settings.json` の断片。非同期キューの 5 つのフック・台帳のフック・権限の allow / deny の骨子 |

## 有償版に入っているもの（¥1,480・Markdown＋HTML の ZIP）

- 第 2 章 棚上げキュー——PENDING / INBOX / 番兵 / フック。なぜその形か。依存する作業と続行する作業を両方書く書式
- 第 3 章 無人実行の 4 つのブレーキ——回数・費用・無進捗・不可逆操作の前の昇格。どこに置くか（外部プロセス／フック／文書）
- 第 4 章 独立セッションの監査——判断監査と検証監査の型。渡すもの／渡さないもの。結果を受け取った直後にファイルへ書く理由
- 第 5 章 記録は機械が書く——SubagentStop → CSV の台帳。モデル・トークン・概算コスト
- 第 6 章 失敗の記録（中核）——60 回の確認で無人実行が壊れた／監査結果が会話にしか無くて消えた／フック出力の文字化け／期限切れ項目の自動取り下げ／「念のため確認します」問題／dry-run 通過＝配管が動く、ほか 14 件
- 第 7 章 テンプレ一式——CHARTER の骨子・監査役の定義（agents/*.md 3 本）・STATUS / NEXT の骨子（無料版の 4 ファイルを含む）

入手方法は道具の README（「有償版」の節）にあります。
