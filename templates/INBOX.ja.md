# INBOX — 人からエージェントへ

メモ帳で開いて、下の `---` より下に 1 行書くだけでよい。エージェントを起動する必要はない。
**書いた行はチャットに書いたのと同じ扱いで読まれる**——エージェントが動いている最中でも次のツール呼び出しの直後に
文脈へ入り（フックが注入）、未読が残ったまま終わろうとすると差し止められる（既定 2 回。従うかはエージェント次第）。
このファイルは UTF-8 で保存する（メモ帳なら「名前を付けて保存 → 文字コード UTF-8」。ANSI だと日本語が化ける）。

```
書き方の例

P-001 done                        依頼を完了した（番号は PENDING.md の項目のもの）
P-001 done https://example.com    完了したうえで結果も伝える
P-001 却下。当面やらない            やらないと決めた
P-002 Excel の転記が面倒            自由文で答える
方針を変える: …                    番号のない連絡もよい
```

- 何行書いてもよい。順序も問わない。行を消す必要はない
- **エージェントが読んだ行には行頭に `✔` が付く**。付いていれば読まれたということ
- `>` で始まる行と `# `（# と空白）で始まる見出し行は読まれない（メモ用）。`#1 done` のような行は読まれる
